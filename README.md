# Kleine Werft

Ein Spiel für Kinder ab 5: Schiffe in der Werft bauen und damit übers Meer fahren – Häfen, Containerkran, Wracks zum Tauchen.

**Spielen / installieren:** https://pascalrauch1989.github.io/kleine-werft/
Auf dem Android-Tablet in Chrome öffnen → Menü ⋮ → „App installieren“. Danach läuft das Spiel komplett offline.
Neue Versionen lädt die App still im Hintergrund, sobald das Tablet online ist; sie gelten ab dem nächsten Start.

Spielstände bleiben nur auf dem Gerät. Im Elternbereich lassen sie sich als Datei sichern und wieder laden.
